# Daylight
An open-source exposure scanner for internal networks, built from real penetration-testing experience. Every check is a weakness I regularly find and exploit on engagements to move laterally and reach domain admin, SMB/LDAP signing gaps, coercion exposure, ADCS misconfigurations, legacy protocols and end-of-life systems. Instead of a generic benchmark, Daylight reports these the way a tester would: prioritised by the real attack path, with evidence and exact remediation steps. Run it on your own network, get a clear HTML report, and fix what an attacker would use first. Updated regularly as I encounter new common weaknesses in the field.
